# Asset Images

This directory should contain the following placeholder images:

## Required Images:
- `logo-placeholder.png` - App logo placeholder
- `product-placeholder.png` - Product image placeholder  
- `category-placeholder.png` - Category image placeholder
- `brand-placeholder.png` - Brand logo placeholder
- `hero-banner.jpg` - Hero banner background
- `usa-flag.png` - USA flag image

## Image Specifications:
- Logo: 180x40px, PNG with transparency
- Product placeholder: 300x300px, PNG
- Category placeholder: 400x300px, PNG  
- Brand placeholder: 120x80px, PNG with transparency
- Hero banner: 1200x600px, JPG
- USA flag: 120x80px, PNG

## Notes:
These are placeholder references. In a production app, you would:
1. Add actual image files to this directory
2. Use react-native-asset or similar tools to link them
3. Reference them using require() statements in components
